About this Project

This application predicts agriculture crop yield using a Random Forest Regression model trained on historical crop production data from India. It helps farmers and policymakers estimate expected yield based on cultivation and production costs.

Features

  • • Crop & State selection
  • • Cost-based inputs
  • • Real-time ML prediction
  • • Downloadable report
