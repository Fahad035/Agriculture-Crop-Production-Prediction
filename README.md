# 🌾 Project 1 – Agriculture Crop Production Prediction

## 📌 Overview

The **Agriculture Crop Production Prediction** system uses Machine Learning to estimate agricultural crop production based on the available input features, including crop type, state information, and production-related costs.

The objective is to demonstrate how predictive analytics can support agricultural planning and provide data-driven insights into crop production.

The project combines a custom web frontend with a Machine Learning prediction workflow to provide users with an interactive prediction experience.

## ✨ Features

- 🌾 Crop Selection
- 📍 State Selection
- 💰 Agricultural Cost Inputs
- 🤖 Random Forest-Based Prediction
- 📄 Downloadable Prediction Report

# 🚦 Project 2 – Smart City Traffic Forecasting

## 📌 Overview

The **Smart City Traffic Forecasting** application predicts traffic volume at different city junctions using historical traffic data and Machine Learning.

The application provides intelligent traffic forecasting through an interactive dashboard with analytics, traffic status information, and downloadable prediction reports.

The project demonstrates how Machine Learning can support traffic monitoring and data-driven urban planning.

## ✨ Features

- 🚦 Junction Selection
- 📅 Date Selection
- 🕒 Hour Selection
- 📈 Traffic Volume Prediction
- 🚗 Traffic Status Classification
- 📊 Interactive Analytics
- 📉 24-Hour Traffic Trend
- 📄 Downloadable Prediction Report
- 🎨 Professional Streamlit Dashboard
- ☁️ Streamlit Cloud Deployment

## 📊 Model Performance

| Model | MAE | RMSE | R² Score |
|---|---:|---:|---:|
| Linear Regression | 9.64 | 12.77 | 0.60 |
